# Guide Utilisateur Client

## 1. Introduction

### À quoi sert l'application ?

Cette application permet à un client de :

- préparer une demande de devis d'assurance automobile ;
- comparer des propositions de plusieurs compagnies ;
- transmettre les documents nécessaires ;
- suivre la validation de son dossier ;
- payer un devis validé ;
- récupérer ensuite son contrat et ses documents.

### À qui s'adresse ce guide ?

Ce guide s'adresse aux clients finaux de la plateforme :

- particuliers ;
- collaborateurs rattachés à une organisation partenaire ;
- adhérents qui souhaitent demander, comparer, acheter et suivre leur assurance automobile.

### Quels problèmes l'application résout-elle ?

L'application centralise tout le parcours client dans un seul espace :

- création d'une demande de devis ;
- comparaison de plusieurs offres ;
- suivi de l'avancement du dossier ;
- dépôt des pièces justificatives ;
- paiement en ligne ;
- accès au contrat après achat.

### Les 3 notions à connaître

- **Simulation** : brouillon de votre demande. Elle contient les informations du véhicule, la formule choisie et les garanties souhaitées.
- **Devis** : proposition chiffrée émise par une compagnie d'assurance.
- **Contrat** : document final actif après validation et paiement.

## 2. Rôles Utilisateurs

### Client

Le client peut :

- créer son compte ;
- se connecter à son espace ;
- lancer des simulations ;
- générer et comparer des devis ;
- télécharger ses documents ;
- payer un devis validé ;
- consulter ses contrats ;
- suivre ses notifications.

### Client rattaché à une organisation

Un client peut être lié à une organisation partenaire lors de l'inscription. Dans ce cas :

- certaines conventions peuvent être appliquées automatiquement ;
- plusieurs conventions peuvent parfois être proposées au choix ;
- des réductions négociées peuvent être prises en compte dans les devis.

### Équipe ARS

L'équipe ARS intervient en arrière-plan pour :

- vérifier les devis soumis ;
- valider ou refuser un dossier ;
- ajouter un commentaire si nécessaire ;
- confirmer le passage au contrat.

Le client ne gère pas ces actions, mais il voit leurs effets dans les statuts, les notifications et les commentaires reçus.

## 3. Prise En Main

### Avant de commencer

Préparez si possible les éléments suivants :

- l'immatriculation du véhicule, si elle est déjà connue ;
- la puissance fiscale ;
- le nombre de places ;
- la valeur à neuf ;
- la valeur vénale ;
- la date de première mise en circulation ;
- la classe bonus/malus ;
- le type d'usage ;
- vos documents justificatifs principaux.

### Créer un compte

Depuis l'écran d'inscription, vous pouvez :

1. saisir vos informations personnelles ;
2. renseigner votre e-mail et votre mot de passe ;
3. ajouter votre téléphone si besoin ;
4. indiquer un code organisation et une clé d'accès si vous dépendez d'une organisation partenaire ;
5. valider l'inscription ;
6. saisir le code de vérification reçu par e-mail.

Une fois la vérification terminée, votre compte est prêt à l'emploi.

### Se connecter

Vous pouvez vous connecter avec :

- votre e-mail et votre mot de passe ;
- ou la connexion Google, si elle vous est proposée.

### Mot de passe oublié

Si vous avez oublié votre mot de passe :

1. ouvrez l'écran de réinitialisation ;
2. saisissez votre e-mail ;
3. récupérez le code reçu par e-mail ;
4. définissez un nouveau mot de passe.

### Navigation générale

Une fois connecté, le menu principal donne accès aux espaces suivants :

- **Tableau de bord**
- **Nouvelle simulation**
- **Mes simulations**
- **Mes devis**
- **Mes contrats**
- **Mes documents**
- **Notifications**
- **Paramètres**

Un champ de recherche dans l'en-tête permet aussi de retrouver rapidement :

- une simulation ;
- un devis ;
- un contrat.

## 4. Fonctions Principales

### 4.1 Tableau de bord

Le tableau de bord vous donne une vue rapide de votre activité :

- nombre de devis générés ;
- simulations en brouillon ;
- demandes en attente ;
- devis validés ;
- activité récente ;
- accès rapide aux actions principales.

### 4.2 Créer une simulation

La création d'une simulation se fait en plusieurs étapes.

#### Étape 1 : renseigner le véhicule

Vous devez saisir :

- l'immatriculation, si elle existe ;
- la puissance fiscale ;
- le nombre de places ;
- la date de première circulation ;
- la valeur à neuf ;
- la valeur vénale.

L'application vérifie notamment que :

- la date n'est pas dans le futur ;
- la valeur à neuf est supérieure ou égale à la valeur vénale ;
- les champs obligatoires sont remplis.

#### Étape 2 : renseigner le profil d'assurance

Vous devez choisir :

- la classe bonus/malus ;
- le type d'usage du véhicule.

Ces informations influencent directement les devis proposés.

#### Résultat attendu

À la fin de cette étape, vous pouvez passer à la sélection de la couverture.

#### Erreurs possibles visibles à l'écran

- date non valide ;
- valeur à neuf inférieure à la valeur vénale ;
- usage non sélectionné ;
- bonus/malus non sélectionné ;
- champ obligatoire manquant.

### 4.3 Choisir la couverture

Cette étape est la plus importante. Elle détermine les formules, compagnies et garanties à comparer.

#### A. Convention

Selon votre compte :

- si vous avez une seule convention active, elle est appliquée automatiquement ;
- si vous avez plusieurs conventions, vous choisissez celle à utiliser ;
- si vous n'en avez aucune, les devis sont générés sans réduction conventionnelle.

#### B. Fractionnement

Vous choisissez le rythme de paiement souhaité :

- **Annuel**
- **Semestriel**

En semestriel, la prime est recalculée sur une base de paiement en deux fois.

#### C. Formule

Vous choisissez une formule parmi celles qui sont disponibles pour votre situation :

- **Standard**
- **Dommages Collision**
- **Tous Risques**

Certaines formules peuvent être indisponibles selon :

- l'âge du véhicule ;
- le type d'usage ;
- la compagnie sélectionnée.

Si une formule n'est pas autorisée, l'application affiche un message expliquant la raison.

#### D. Choisir la ou les compagnies

Vous pouvez comparer jusqu'à **2 compagnies**.

Conseil :

- sélectionnez 1 compagnie si vous voulez aller vite ;
- sélectionnez 2 compagnies si vous voulez comparer deux offres sur la même base.

#### E. Garanties optionnelles

Vous pouvez ensuite ajouter des garanties optionnelles selon la formule choisie.

Important :

- certaines garanties sont toujours incluses automatiquement ;
- certaines garanties sont cachées ou indisponibles selon la compagnie ;
- certaines peuvent être incluses gratuitement dans certains cas ;
- certaines demandent un choix complémentaire avant validation.

#### F. Choix complémentaires possibles

Selon votre sélection, l'application peut vous demander :

- un **taux de franchise** pour la formule Tous Risques ;
- une **limite Bris de Glaces** ;
- un **capital Dommages Collision** pour chaque compagnie sélectionnée ;
- un **capital Assurance Conducteur** pour chaque compagnie sélectionnée.

#### Résultat attendu

Quand la formule, la ou les compagnies et les éléments obligatoires sont correctement choisis, vous pouvez passer à la génération des devis.

#### Erreurs ou blocages possibles

- aucune compagnie sélectionnée ;
- formule indisponible pour le véhicule ;
- capital Dommages Collision non renseigné pour toutes les compagnies ;
- sélection impossible selon les règles d'éligibilité.

### 4.4 Générer les devis

Une fois la simulation prête, l'application :

1. enregistre votre simulation ;
2. calcule un devis pour chaque compagnie sélectionnée ;
3. affiche le total et le détail des garanties.

Pour chaque devis, vous voyez notamment :

- la compagnie ;
- le numéro de devis ;
- le total à payer ;
- la prime nette ;
- les frais ;
- les taxes ;
- le détail des garanties.

Certaines lignes peuvent apparaître comme :

- **gratuites** ;
- **non accordées**.

Cela signifie que la compagnie applique une règle particulière à cette garantie dans votre cas.

### 4.5 Télécharger le PDF du devis

Après génération, vous pouvez télécharger le devis en PDF :

- depuis l'étape de confirmation ;
- depuis la liste des devis ;
- depuis le détail d'une simulation.

Le PDF est utile pour :

- garder une copie ;
- partager l'offre ;
- relire les garanties avant soumission.

### 4.6 Téléverser les documents justificatifs

Avant de soumettre votre demande, vous pouvez déposer vos pièces justificatives.

#### Documents obligatoires

Pour soumettre un devis, les documents obligatoires sont :

- **Carte grise**
- **Carte d'identité nationale (CIN)**

#### Documents complémentaires possibles

Selon le dossier, vous pouvez aussi ajouter :

- permis de conduire ;
- visite technique ;
- vignette ;
- RNE.

#### Bon à savoir

- les documents sont associés à votre compte ;
- la dernière version téléversée remplace la précédente pour un même type de document ;
- vous pouvez les visualiser avant envoi ;
- leur état peut apparaître comme **validé** ou **en attente**.

### 4.7 Soumettre un devis pour validation

Quand les documents obligatoires sont présents, vous pouvez soumettre votre demande.

#### Ce que fait l'application

- le devis passe en attente de validation ;
- l'équipe ARS est notifiée ;
- vous recevez également une confirmation.

#### Résultat attendu

Le statut change et votre dossier entre en phase d'examen.

#### Erreurs possibles

- documents obligatoires manquants ;
- tentative de soumission d'un dossier déjà soumis ;
- information manquante dans la simulation.

### 4.8 Gérer ses simulations

La page des simulations vous permet de :

- voir l'historique de vos demandes ;
- consulter le détail de chaque simulation ;
- voir les devis déjà générés ;
- télécharger un devis ;
- supprimer une simulation si aucun devis n'y est encore attaché.

#### Statuts possibles d'une simulation

- **Brouillon**
- **Soumise**
- **Approuvée**
- **Rejetée**

### 4.9 Gérer ses devis

La page des devis est votre espace principal de suivi.

Vous pouvez :

- filtrer les devis par date ;
- filtrer par classe fiscale ;
- filtrer par formule ;
- télécharger les PDF ;
- comparer plusieurs devis ;
- consulter les commentaires de l'équipe ;
- acheter un devis validé.

#### Statuts possibles d'un devis

- **Généré** : le devis est calculé mais pas encore soumis ;
- **Soumis** : il est en cours d'examen ;
- **Validé** : vous pouvez passer au paiement ;
- **Rejeté** : il n'a pas été retenu ou un autre devis de la même simulation a été transformé en contrat ;
- **Transformé en contrat** : le devis a déjà été converti en contrat.

#### Historique

Les devis déjà transformés en contrat sont retirés de la liste principale et conservés dans l'historique.

### 4.10 Comparer plusieurs devis

Vous pouvez sélectionner plusieurs devis, puis ouvrir l'écran de comparaison.

La comparaison affiche côte à côte :

- le total TTC ;
- la prime nette ;
- les frais ;
- les taxes ;
- les frais additionnels ;
- les garanties incluses.

Cette vue est utile pour choisir l'offre la plus adaptée, pas seulement la moins chère.

### 4.11 Acheter un devis validé

Un devis validé peut être acheté directement depuis votre espace.

#### Conditions pour acheter

Le bouton d'achat n'apparaît que si :

- le devis est validé ;
- aucun autre devis de la même simulation n'a déjà été transformé en contrat.

#### Étape 1 : choisir la date d'effet

Vous devez sélectionner une date de début de couverture.

Règles importantes :

- la date ne peut pas être dans le passé ;
- après 16h, la date du jour peut devenir indisponible ;
- le week-end le plus proche peut être bloqué ;
- l'application propose automatiquement la première date autorisée.

#### Étape 2 : choisir le mode de livraison

Deux options sont disponibles :

- **Retrait à l'agence** : sans frais de livraison ;
- **Livraison à domicile** : avec frais supplémentaires.

La livraison à domicile ajoute **10 DT** au total à payer.

#### Étape 3 : compléter l'adresse si nécessaire

Si vous choisissez la livraison à domicile, vous devez renseigner :

- prénom ;
- nom ;
- gouvernorat ;
- délégation ;
- localité ;
- code postal ;
- téléphone ;
- e-mail ;
- notes éventuelles.

#### Étape 4 : accepter les conditions

Avant paiement, vous devez confirmer que les informations fournies sont exactes.

#### Étape 5 : payer en ligne

Le paiement se fait via la passerelle **Flouci**.

#### Résultat attendu

Après paiement réussi :

- le devis est transformé en contrat ;
- le contrat devient actif ;
- les autres devis de la même simulation ne sont plus achetables ;
- vous recevez une confirmation.

#### Erreurs possibles

- devis non validé ;
- date d'effet non autorisée ;
- adresse de livraison manquante ;
- paiement annulé ;
- devis non disponible car un autre devis de la même simulation a déjà donné lieu à un contrat.

### 4.12 Consulter ses contrats

La page des contrats vous permet de :

- voir tous vos contrats ;
- consulter leur statut ;
- ouvrir le détail ;
- télécharger le PDF ;
- consulter les documents liés.

#### Informations disponibles

Vous retrouvez notamment :

- le numéro du contrat ;
- la compagnie ;
- la période de couverture ;
- le mode de livraison ;
- les frais de livraison ;
- les garanties couvertes ;
- le montant payé ;
- la quittance si elle est disponible.

#### Statuts possibles d'un contrat

- **Actif**
- **Suspendu**
- **Annulé**
- **Expiré**

### 4.13 Gérer ses documents

L'espace documents vous aide à :

- voir les documents déjà transmis ;
- vérifier leur statut ;
- les consulter ;
- supprimer ceux qui ne sont plus corrects ;
- tenir votre dossier à jour.

### 4.14 Notifications

Les notifications vous informent en temps réel des événements importants, par exemple :

- devis créé ;
- devis soumis ;
- devis validé ;
- devis rejeté ;
- documents demandés ;
- contrat créé.

Vous pouvez :

- afficher toutes les notifications ;
- filtrer les non lues ;
- marquer une notification comme lue ;
- tout marquer comme lu.

### 4.15 Paramètres

Depuis les paramètres, vous pouvez :

- mettre à jour vos informations personnelles ;
- changer votre mot de passe ;
- ajuster vos préférences d'affichage ;
- gérer vos préférences de notification.

## 5. Workflows Clés

### Workflow 1 : Créer et soumettre une demande de devis

1. Connectez-vous.
2. Ouvrez **Nouvelle simulation**.
3. Renseignez le véhicule.
4. Renseignez la classe bonus/malus et l'usage.
5. Choisissez la convention si besoin.
6. Choisissez le fractionnement.
7. Choisissez la formule.
8. Sélectionnez 1 ou 2 compagnies.
9. Ajoutez les garanties optionnelles souhaitées.
10. Renseignez les éléments complémentaires si l'application vous les demande.
11. Générez les devis.
12. Relisez le détail et le PDF.
13. Téléversez vos documents.
14. Soumettez le dossier pour validation.

### Workflow 2 : Comparer plusieurs offres

1. Ouvrez **Mes devis**.
2. Cochez les devis à comparer.
3. Lancez la comparaison.
4. Analysez le total, les frais et les garanties incluses.
5. Conservez le devis le plus adapté à votre besoin.

### Workflow 3 : Acheter un devis validé

1. Attendez que le devis passe au statut **Validé**.
2. Ouvrez le devis.
3. Cliquez sur **Acheter ce devis**.
4. Choisissez la date d'effet.
5. Choisissez le mode de livraison.
6. Renseignez l'adresse si vous choisissez la livraison à domicile.
7. Acceptez les conditions.
8. Procédez au paiement.
9. Revenez dans **Mes contrats** pour retrouver votre contrat actif.

### Workflow 4 : Gérer un retour de l'équipe ARS

1. Surveillez vos notifications.
2. Ouvrez le devis concerné.
3. Lisez le motif de rejet ou la note laissée par l'équipe.
4. Si nécessaire, corrigez vos documents ou relancez une nouvelle simulation.
5. Si le devis a été modifié puis validé, vous pouvez passer directement à l'achat.

## 7. Bonnes Pratiques

- Vérifiez soigneusement la date de première circulation et les valeurs du véhicule avant de générer un devis.
- Si vous comparez deux compagnies, gardez exactement la même configuration pour que la comparaison soit utile.
- Téléversez des documents lisibles, complets et à jour.
- Si vous appartenez à une organisation, utilisez le bon code d'accès dès l'inscription pour bénéficier des conventions disponibles.
- Consultez toujours les commentaires ou motifs affichés sur un devis rejeté ou modifié.
- Ne tardez pas à payer un devis validé si vous avez choisi votre compagnie.
- N'oubliez pas qu'un seul devis d'une même simulation peut être transformé en contrat.
- Pour aller plus vite, préparez à l'avance votre CIN et votre carte grise.
- Si vous choisissez la livraison à domicile, remplissez l'adresse avec précision pour éviter un retard.
- Relisez la date d'effet proposée avant paiement.

## 8. FAQ Et Problèmes Courants

### Je ne vois aucune convention. Est-ce normal ?

Oui. Si votre compte n'est rattaché à aucune organisation ou si aucune convention active ne vous est attribuée, les devis seront générés sans réduction conventionnelle.

### Une formule est grisée ou indisponible. Pourquoi ?

La formule peut être bloquée selon l'âge du véhicule, l'usage choisi ou les règles propres à la compagnie sélectionnée.

### Je ne peux pas continuer après avoir choisi Dommages Collision.

Vérifiez que vous avez bien défini un capital Dommages Collision pour chaque compagnie sélectionnée.

### Pourquoi certaines garanties ne s'affichent pas ?

Certaines garanties sont :

- déjà incluses automatiquement ;
- masquées car non disponibles pour la formule choisie ;
- regroupées avec une autre garantie ;
- indisponibles chez la compagnie sélectionnée.

### Pourquoi Bris de Glaces peut apparaître gratuitement ?

Dans certaines configurations, cette garantie peut être incluse sans surcoût. L'application vous l'indique directement.

### Je ne peux pas soumettre mon devis.

Le cas le plus fréquent est l'absence des documents obligatoires :

- carte grise ;
- CIN.

### Je vois un motif de rejet. Que dois-je faire ?

Lisez le commentaire affiché sur le devis, corrigez ce qui est demandé, puis relancez une nouvelle demande si nécessaire.

### Je ne peux pas acheter un devis validé.

Cela arrive généralement si un autre devis issu de la même simulation a déjà été transformé en contrat.

### Pourquoi la date du jour n'est-elle pas disponible ?

La date d'effet dépend de règles de disponibilité. Selon l'heure et le jour, la date du jour ou le week-end le plus proche peuvent être bloqués.

### Les autres devis disparaissent-ils après achat ?

Ils restent conservés dans l'historique, mais ils ne sont plus achetables si l'un des devis de la même simulation a déjà donné lieu à un contrat.

### Mes documents servent-ils pour plusieurs devis ?

Oui. Vos documents sont rattachés à votre compte et peuvent être réutilisés pour vos demandes suivantes, tant que la version fournie reste correcte.

### Que faire si mon paiement est annulé ?

Vous pouvez revenir à votre devis et recommencer le paiement. Aucun montant n'est débité tant que le paiement n'est pas confirmé.
